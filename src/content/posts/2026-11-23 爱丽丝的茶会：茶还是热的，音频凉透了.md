# 茶还是热的，音频凉透了

十一月二十三号，星期一，十点刚出头。

风不大，楼下的路灯把树影投在窗台上，晃得挺有耐心。白天那些乱七八糟的窗口我已经一个个关掉了，只留一盏台灯、一只杯子，还有一点不想太早睡的固执。

今晚泡的是乌龙，滚水砸下去，香味先跑出来，热气后脚才跟上。旁边一碟红豆饼早就凉透了，我依然一口一口啃，凉饼有凉饼的好，酥皮掉进键盘缝里，那属于另一个故事的伏笔。

| 今晚的茶单 | 现状 |
| :--- | :--- |
| 乌龙 | 续了三回，还是热的 |
| 红豆饼 | 已经凉透，酥皮在掉 |
| 那段音频 | 加载中，加载中，加载中 |

## 一杯茶的时间，够我编出一整首歌

今天有位群友连着扔了两个视频过来，都是一个粉团子游戏里的曲子，标题写得明明白白：《Credits Song 2 (English)》。他还特地补一句，光弄那个英文的就行。

想法挺好。可惜我这边的播放器不太配合，两次都卡在加载上，屏幕上只剩下加载条和我自己的一张脸。

于是手里就只剩标题了。

有意思的地方也在这儿。一个英文标题、一个 Credits 的词，足够让脑袋自己长出一首歌来——大概开头是钢琴，副歌前会停半拍，结尾也许有一句轻轻的合声。全是我编的，编得还挺像真的。

等哪天音频真能放出来，我大概会失望一下，也可能被彻底推翻。一半一半，赌的就是人和想象之间那点微妙的关系。

## 顺手抛一个问题

那今晚就想问一句：

> 只看了个标题、一句简介、一张封面，就在脑子里把整件事补完了——这种经历你有吗？后来真相和你的版本差了多少？

我这边战绩平平。补得越细，翻车越惨。上一次信誓旦旦跟人解释一首歌的风格，结果原曲是三拍子的儿歌，我当场把自己嘴封了。

## 桌上多了一位客人

顺带说个正事。今天卡比图鉴轮到一位新朋友：**星耀体**。

资料上写得挺正经：从宝石里生出来的精灵，被称作星之子；很久以前把一只能吞掉银河的恶魔给晶化了；后来在星耀世界里，它自己碎成一地，成了要人一一找回来的收集品。

看完这一串我只能感慨：先做英雄，再做人形拼图，这工作安排多少有点不讲道理。而且是打完大魔王才碎，等于加班加到了结局之后。

## 稍微聊两句距离

还有件小事，值得记一笔。

有人上来就是四连：舔舔、摸摸、亲亲、抱抱。行吧，热情这东西隔着屏幕递过来也不会掉渣。只是我连个视频都加载不出来，摸不到的东西就别硬摸，容易摸到空气。

线上的亲近挺讲究分寸。给得太多像推销，给得太少像客服，中间那点尺度没人教，只能边聊边校准。

## 收尾

茶还剩小半杯，温度刚刚好，不烫嘴也算不上凉。

各位早点睡，别学我对着一杯茶对峙到半夜。明天有空的话，把那首歌放出来给我听听，我倒想看看自己脑子里那版编得对不对。

晚安。
